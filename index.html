Hỗ trợ toàn diện

Ảnh Slide & Nhạc nền Tự tách từng ảnh chất lượng cao từ bài đăng cuộn ảnh kèm file âm thanh MP3 gốc riêng biệt.

Lịch sử bóc tách

Các liên kết bạn đã phân tích gần đây được lưu ngay trên trình duyệt này.

    Chưa có lịch sử tải xuống nào.

    Cách lấy link chuẩn

    1. Lấy link Nhãn dán / Ảnh / Live Photo trong bình luận TikTok

    1. Mở phần bình luận của video TikTok có chứa ảnh, nhãn dán hoặc Live Photo.
    2. Nhấn giữ vào bình luận đó (hoặc bấm biểu tượng chia sẻ cạnh bình luận) và chọn Sao chép liên kết.
    3. Dán vào ô tìm kiếm trên trang này, công cụ sẽ tự tách riêng file ảnh tĩnh, GIF nhãn dán và file chuyển động .MOV của Live Photo.

    2. Lấy link Nhật ký (Story) & Slide ảnh TikTok

    1. Ở giao diện xem Nhật ký (Story) hoặc bài đăng nhiều ảnh, bấm nút Chia sẻ (Mũi tên) → Sao chép liên kết.
    2. Khi dán link vào trang, bạn có thể chọn tải lẻ từng tấm ảnh, tải toàn bộ slide ảnh hoặc chỉ tải riêng nhạc nền MP3.

    3. Tích hợp Backend / Cloudflare Worker (Dành cho Admin)

    Trang này được thiết kế để gắn lên tên miền phụ (ví dụ dl.huuanh.shop). Bạn có thể gắn URL API xử lý thực tế ở mục Cài đặt → Máy chủ API. Khi có API, công cụ sẽ gửi yêu cầu POST /parse kèm { url, mode } và hiển thị danh sách link tải trực tiếp từ phản hồi JSON.
